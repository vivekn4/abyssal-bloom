## Sound effects

| Game cue | File | Source |
|---|---|---|
| Glimmerfish caught | `sfx/snd_catch.wav` | **Kenney** — *Interface Sounds* (`pluck_002`), [CC0](https://creativecommons.org/publicdomain/zero/1.0/) |
| Pearl collected | `sfx/snd_pearl.wav` | **Kenney** — *Interface Sounds* (`confirmation_001`), CC0 |
| Anemone lamp wakes | `sfx/snd_lamp.wav` | **Kenney** — *Interface Sounds* (`open_002`), CC0 |
| Reef-bloom victory fanfare | `sfx/snd_win.wav` | **Kenney** — *Music Jingles* (`jingles_NES00`, 8-bit), CC0 |
| Splash / dive transitions | `sfx/snd_splash.wav` | Synthesized for this project by VN (Kenney has no water SFX; public-domain dedication) |
| Underwater ambience loop (8s) | `sfx/snd_bubbles_loop.wav` | Synthesized for this project by VN (public-domain dedication) |

All `.wav` files are 16-bit mono 22050 Hz — GameMaker-ready. Kenney's full license text is bundled as `sfx/KENNEY-LICENSE.txt`. Kenney does not require attribution, but credit is given gladly: audio packs by [Kenney](https://kenney.nl).

> Want fully hand-made SFX instead? [Kenney.nl](https://kenney.nl/assets?q=audio) offers CC0 audio packs (no attribution required) — their *RPG Audio* and *Interface Sounds* packs include bubbles, splashes, and pickup chimes that fit this game. Drop any `.wav` into GameMaker's Sounds folder and rename to match the names above.
